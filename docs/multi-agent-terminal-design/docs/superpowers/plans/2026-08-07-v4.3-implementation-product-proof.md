# v4.3 Implementation and Product-Proof Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the v4.2 package into a validated v4.3 implementation and product-proof baseline without expanding speculative product breadth.

**Architecture:** Keep historical contracts immutable and introduce v4.3 contracts as v7/v3/new v1 schemas. The application reducer owns semantic transition decisions; SQLite requires an immutable accepted transition event and enforces critical route/evidence/effect invariants. Protocol documentation is checked as code, while provider configuration, assurance degradation, orchestration experiments, and traceability are immutable typed artifacts.

**Tech Stack:** Markdown, JSON Schema Draft 2020-12, SQLite STRICT tables/triggers, Python 3, `jsonschema`, ZIP/SHA-256 tooling.

## Global Constraints

- Preserve local-first operation, single-writer fencing, immutable evidence, exact-object approval, crash fail-closed behavior, and historical migration inputs.
- Do not claim real-agent, model-quality, containment, or product-market evidence that was not executed.
- Credentials are references only and never appear in run artifacts.
- Fallback always creates a new run and a visible assurance decision.
- Profile escalation is monotonic; downgrade is forbidden within a task.
- No broad memory, remote-agent, marketplace, billing, or multi-user scope is added.
