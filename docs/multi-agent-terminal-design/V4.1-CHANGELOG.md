# v4.1 Change Log

> **Historical v4.1 changelog.** Current changes are recorded in `V4.1.1-CHANGELOG.md`.

## Added

- Authoritative State Store with fixed precedence and immutable resolution receipts.
- Cognitive memory JSON Schema v2.
- Agent quality benchmark JSON Schema v2 with four controlled experiment arms.
- SQLite v4 clean-install contract and additive v3-to-v4 migration.
- Typed invalidation rules and immutable evaluations.
- Retrieval eligibility gate requiring current passing invalidation evidence.
- Shadow evaluation and deterministic/policy promotion gate.
- Memory usage events, utility snapshots, and consolidation actions.
- Adaptive context budget decisions and stopping reasons.
- Nine-case bootstrap context/memory benchmark corpus.
- v4.1 validation and traceability suites.

## Changed

- Current preferences, task overrides, and active settings are resolved as state rather than generic memory.
- Static context percentages are fallback profiles rather than normative allocation.
- MVP prioritizes state, evidence, negative/procedural memory, invalidation, and controlled measurement.
- `sqlite-v4.sql`, `cognitive-memory.v2.schema.json`, and `agent-quality-benchmark.v2.schema.json` are normative for v4.1.

## Preserved

- v3.2 and v4.0 authority, safety, recovery, approval, and protocol regressions.
- Immutable memory lifecycle and source provenance.
- Local-first and replaceable retrieval boundaries.

## Not claimed

- Runtime agent quality improvement.
- Production retrieval precision or latency.
- Safe autonomous consolidation.
- Installed-product containment of optional external retrieval adapters.
