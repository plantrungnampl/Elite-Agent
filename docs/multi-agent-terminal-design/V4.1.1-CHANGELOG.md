# v4.1.1 Changelog

## Added

- Cognitive schema v3 with root-reachable v4.1.1 records.
- SQLite v5 clean contract and v4→v5 migration.
- Explicit state-resolution conflict records and one-to-one conflict receipts.
- State terminal timestamp migration backfill.
- Candidate-time, actor-binding-digest-and-evidence-bound memory-origin records.
- Benchmark run-arm and exact memory-binding records.
- Cross-scope and stale-memory shadow regression counters.
- Exact retrieval/context linkage for memory usage evidence.
- Maximum context budget plus output and verification reserves.
- v4.1.1 examples and a 60-check adversarial validation suite.

## Changed

- State must start active and valid at creation.
- Equal-precedence divergent state requires a recorded conflict before resolution.
- Invalidation SQL now validates the complete typed rule contract.
- Retrieval uses applicable, non-future, current invalidation evaluations.
- Experience memory context items require selected retrieval candidates from the same preallocated package run.
- Included/downstream usage events require both the exact candidate and exact context item.
- Origin exceptions require coherent actor identity, actor-binding digest, exact evidence, and must exist before verification; verified legacy memory cannot be reclassified.
- Policy/deterministic promotion rechecks exact shadow isolation and latest result.
- Consolidation application requires observable lifecycle or relation effects.
- Budget allocations accept integers only and include reserves in the hard limit.

## Deferred

- Autonomous memory splitting.
- Broad semantic extraction and inferred preference activation.
- Runtime claims of improved retrieval or task success.
