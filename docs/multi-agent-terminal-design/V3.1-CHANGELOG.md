# v3.1 Change Log

- Added 12 regression checks for unsafe operations discovered after the v3 audit; the executable suite now contains 39 checks.
- Enforced `row_version = OLD.row_version + 1` on every task update, not only statements that explicitly targeted the version column.
- Added agent-run scope binding across task, agent, role, context package, run configuration artifact, and superseded run; expanded immutable run identity to role and phase.
- Added message scope binding across task, run, artifact, reply thread, and supersession thread; message authority identity is immutable.
- Made operation-attempt history non-deletable and changed set-once evidence comparisons to SQLite NULL-safe `IS NOT` semantics.
- Added protocol request task/run scope, task-scoped completion evidence, NULL-safe set-once response evidence, and delete guards for request and stream sequence history.
- Updated the review matrix, invariant registry, remediation map, validation report, generated results, and package checksums.
- Capability policy is unchanged: structural hardening does not enable filesystem/Git writes, final commit, external workers, or third-party adapters without their runtime release gates.
