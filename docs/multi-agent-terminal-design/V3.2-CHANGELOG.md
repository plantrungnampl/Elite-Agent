# v3.2 Change Log

v3.2 is a contract-hardening and self-review release. It does not expand product scope or enable write/external execution capabilities.

## Authority and evidence hardening

- Made schema migration records immutable and retained.
- Bound artifact task/project scope, immutable content identity, coherent supersession, and retained-metadata and quarantine-before-byte-GC behavior; v4 maintenance also blocks lifecycle resurrection and identity replacement.
- Made artifact operation identity/evidence durable and terminal states irreversible.
- Bound operation intents to same-task runs and canonical request artifact digests; retained intent history and required a persisted current attempt before advancing the attempt counter.
- Made policy decisions immutable/retained and bound optional approval references to the same task, operation digest, and actor.
- Required `require_approval` policies to carry the exact granted, unexpired approval selected by policy.
- Required successful attempts to persist task-scoped receipts and prevented terminal aggregate intent state without the matching current terminal attempt.
- Bound tool executions to exact active attempt authority, task-scoped arguments/output evidence, terminal completion evidence, immutable results, and retained history.
- Required approvals to begin pending, use task-scoped request/credential artifacts, resolve with matching immutable receipt time, and retain immutable resolution evidence.
- Bound final-commit approval type and approval consumption to the exact immutable repository/ref/old-OID/candidate-OID tuple.
- Required project repository identity to be an immutable SHA-256 digest.

## Run, protocol, containment, and lifecycle hardening

- Revalidated descriptor enablement and exact-tuple containment attestation when a run is created.
- Made revocation immediately disable the affected external descriptor.
- Retained agent runs and made terminal/usage/error evidence set-once.
- Retained messages, made terminal statuses irreversible, required a replacement for supersession, and made the replacement link set-once.
- Closed protocol completed/failed/pending timestamp inconsistencies, response scope updates, stream-key mutation, request deletion/replay reset, and stream-head reset.
- Made lease expiry immutable, required terminal release time, and retained release evidence.
- Retained update journal history and terminal update outcomes.

## Retrieval and package consistency

- Rejected cross-project source-document, memory-artifact, and repository-graph edges.
- Added a 63-case adversarial hardening suite on top of the original 39-case regression suite.
- Added full package validation for every JSON file, every JSON Schema, all eight examples, Markdown links, workflow/SQLite enum alignment, and placeholder hygiene.
- Added captured red baselines for each self-review pass and a consolidated self-review report.
