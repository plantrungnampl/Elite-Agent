# v4.3 Changelog — Implementation and Product-Proof Baseline

## Added

- SQLite v7 clean-install authority and v6-to-v7 migration.
- Versioned workflow transition rules, immutable transition events, guard/effect bindings, stream-version projection updates, and retry-safe rejected events.
- Monotonic workflow-profile escalation receipts and in-task downgrade prohibition.
- `WorkflowTransitionCommand v1` plus canonical example.
- `RunConfiguration v1`, exact run binding, provider/model reconstruction, explicit fallback, and independence fingerprint.
- `AssuranceDegradationReceipt v1` and actor-proof requirement for continuing under degraded assurance.
- Equal-budget orchestration benchmark suite, run receipt, case result, and comparison report contracts.
- Machine-readable v4.3 traceability for all 51 FR/NFR requirements.
- v4.3 implementation/product-proof, run-configuration, benchmark, self-review, and migration documents.
- Annotated protocol fixtures validated directly from normative Markdown.

## Changed

- Current workflow authority moves from direct phase adjacency to reducer-command/event authority.
- Protocol name is clarified as **MAT Agent Control Protocol v2** to avoid collision with other public “Open Agent Protocol” names.
- Cognitive extension capability remains `cognitive-memory.v1`; its current payload authority is `cognitive-memory.v4.schema.json`.
- Roadmap moves a real read-only runtime and equal-budget single-vs-multi proof before mediated writes and broad memory expansion.
- High Assurance requires explicit role separation and policy-defined independent groups; inability to meet the requirement is visible and receipt-backed.
- Package runner now includes the v4.3 implementation/product-proof suite and validates v7/v3 current authority.

## Preserved

- v4.2 and earlier schemas, migrations, reports, and regression suites remain immutable historical evidence.
- Exact-object approval, one fenced executor, local-first authority, append-only evidence, crash recovery, and cognitive-memory governance remain unchanged unless v4.3 explicitly supersedes them.

## Proof boundary

The release proves contract coherence and closes the encoded bypasses. It does not claim live orchestration lift, external-agent containment on every machine, provider interoperability, or product adoption.
